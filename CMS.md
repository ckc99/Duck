# 用 Sanity 编辑网站 · Editing the website with Sanity

All text, photos, the video and SEO tags are edited at **https://kampar-free-range-duck.sanity.studio/** (Sanity project `3k9cyy6o`).
The site itself stays plain HTML on GitHub Pages, so Google sees normal static pages.

## How an edit reaches the site

1. Edit and **Publish** in Sanity Studio.
2. Within about 30 minutes the GitHub Action **Sync content from Sanity** (`.github/workflows/sanity-sync.yml`) picks it up.
   To see it sooner: repo **Actions** tab → *Sync content from Sanity* → **Run workflow**.
3. `scripts/sanity-sync.mjs` rewrites only the parts of the HTML between `<!-- cms:… -->` and `<!-- /cms:… -->`
   markers, commits, and GitHub Pages redeploys in about a minute.

It refuses to change anything if Sanity returns no products or no WhatsApp number, and a field left empty
never blanks the page (the old content stays).

| In the Studio | Controls |
|---|---|
| **Site Settings & Contact 网站设置** | WhatsApp number, email, Instagram, Facebook, Ipoh & Klang addresses, company name, footer taglines, copyright line, share image — used on every page, every WhatsApp button and the business details Google reads |
| **Home Page 首页** | Hero photo and text, Since 2016, slogan · 培育之道 heading, text, video (MP4) and cover photo, button, duck picture, key numbers · product slider (2 slides: photo, title, text, link) · 服务范围 heading, intro and area cards · 山水鸭的诞生 heading, 4 photos and captions · SEO |
| **About Page 关于我们** | Top banner photo and heading · YouTube video · 3 sections (headings, text, bullet points, photos) · "What We Offer" · SEO |
| **Products Page 产品页 (texts)** | Duck parts heading, wholesale line, button texts · SEO |
| **Product 产品** | The whole duck feature and every duck part card |
| **Supplier Page 供应商** | Top banner · wholesale intro, bullet points, photo · 配送范围 area cards · 常见问题 FAQ (also sent to Google) · bottom call-to-action and its WhatsApp message · SEO |

**Every page has an "SEO — Google & sharing" box**: page title, meta description, and the title/description
shown when the link is shared on Facebook or WhatsApp.

Text tips: press Enter for a new line · `**bold**` · `[link text](page.html)`. In longer texts, leave an empty line to start a new paragraph.

Still edited outside Sanity:
- **Privacy Policy** (`privacy.html`) — generated by Termly; update it in Termly and replace the file.
- Page layout and design, the menu/footer link names, icons, and the large "Kampar Free Range Duck" hero lettering.

**Don't delete or rename the `<!-- cms:… -->` comments** — the sync uses them to know what to replace.

## Optional: instant updates with a webhook

Not needed — the 30-minute check already works. Add this only if you want changes live within a minute.

1. GitHub → Settings → Developer settings → **Fine-grained personal access tokens** → Generate.
   Repository access: only `ckc99/Duck`. Permissions: **Contents: Read and write**. Copy the token.
2. https://www.sanity.io/manage → project **Kampar Free Range Duck 金宝山水鸭** → API → Webhooks → Create:
   - URL: `https://api.github.com/repos/ckc99/Duck/dispatches`
   - Dataset: `production`, Trigger on: Create, Update, Delete
   - Filter: `!(_id in path("drafts.**"))`
   - Projection: `{"event_type": "sanity-publish"}`
   - HTTP method: POST
   - HTTP headers: `Authorization: Bearer <your token>` and `Accept: application/vnd.github+json`

Note: GitHub pauses scheduled actions in a repo with no commits for 60 days. If that happens, the Actions tab shows a banner — click **Enable workflow**.

## Testing locally

```bash
node scripts/sanity-sync.mjs            # pulls live content and rewrites the HTML

```
